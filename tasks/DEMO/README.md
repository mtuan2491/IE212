# DEMO — fixture kiểm ba cổng

Chạy input gate, tạo cặp bằng `python src/ie212_instacart/bootstrap_demo.py` rồi chạy output gate. Fixture có sản phẩm trùng trong một order và cùng cặp ở hai order. Output phải có đúng hai cặp, (3,7) đếm 2 và (3,9) đếm 1. Merge gate chạy fixture logic từ cây merge tạm.
